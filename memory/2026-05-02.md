# 2026-05-02

- Diagnosed `cc-sesh-master` showing `Disconnected` in the browser while PM2 was online.
- Local API `http://localhost:37778/api/tracker/status` returned `200 OK`; PM2 process was healthy.
- Root cause was frontend endpoints hardcoded to `http://localhost:37778`, which fails when the dashboard is opened through another host/proxy because the browser resolves `localhost` on the client machine.
- Updated `dashboard.html` to derive API URLs from `window.location.origin`, with a `file://` fallback to local port `37778`.
- Fixed `serve-dashboard.py` logging so missing static files like `favicon.ico` no longer trigger a `TypeError` traceback in PM2 logs.
- Restarted PM2 process `cc-sesh-master`; API remained healthy afterward.
