# 2026-06-23

- Fixed Codex renamed-session display in CC-sesh-master. Codex stores renamed
  thread titles in `~/.codex/session_index.jsonl`, while the dashboard was only
  deriving `slug` from early session JSONL events. Long/resumed Codex sessions
  can have no usable first-message slug in the first scan window, causing the UI
  fallback `sessionId.slice(0, 8)` to show labels like `codex-01`.
- `serve-dashboard.py` now reads `session_index.jsonl` for each Codex sessions
  directory and prefers `thread_name` for the Codex session slug. Verified
  `codex-019eef2b-21c5-7780-8eba-c3c6f2280263` shows
  `ERP completion. ciclo 3 concluido` and is searchable by that title after
  restarting PM2 process `cc-sesh-master`.
- Codex `resume` picker filters by current working directory by default. Use
  `codex resume --all` or pass the session id/name directly when resuming a
  session from a different project directory.
